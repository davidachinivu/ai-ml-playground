# AI/ML Playground

A comprehensive exploration of modern machine learning and deep learning architectures. This repository showcases hands-on implementations spanning computer vision, natural language processing, generative models, and sequential analysis—demonstrating practical application of complex AI concepts across diverse domains.

## Folder Structure

### CNNs
Advanced convolutional architectures for image classification and feature extraction.
- **CIFAR10.ipynb** - CNN architecture with dropout regularization and overfitting analysis
- **CIFAR_100.ipynb** - Multi-class classification on 100-class dataset with performance optimization
- **CNN_Hyperparameter_Exploration.ipynb** - Systematic analysis of learning rate, epochs, and filter depth impact
- **SVHN.ipynb** - ResNet50 transfer learning for real-world street view digit recognition

### RNNs_LSTMs
Sequential modeling architectures for time series forecasting and natural language processing.
- **LSTM_Networks_for_Stock_Price_Prediction.ipynb** - Financial time series prediction with multi-step forecasting
- **LSTM_for_Temperature_Prediction.ipynb** - API-driven weather data modeling with sequence-to-sequence architecture
- **Character_Level_Language_Modelling.ipynb** - Creative text generation using temperature-controlled sampling
- **LLM_Demo.ipynb** - Language modeling on literary corpus with probabilistic decoding
- **S5_RNN_Text_Classifier_AA.ipynb** - Sentiment analysis with embedding layers and sequence classification

### Transfer_Learning
Pre-trained model adaptation for efficient learning on limited data.
- **Transfer_Learning.ipynb** - MobileNetV2 fine-tuning demonstrating knowledge transfer from ImageNet

### Generative_Models
Probabilistic models for synthetic data generation and representation learning.
- **GAN.ipynb** - Adversarial training framework for synthetic digit generation
- **Variational_Autoencoder_on_Fashion_MNIST.ipynb** - Latent space visualization with variational inference
- **Variational_autoencoders.ipynb** - Encoder-decoder architecture with KL divergence regularization

### Clustering
Unsupervised learning algorithms for pattern discovery and data segmentation.
- **S8_Clustering_Techniques_AA.ipynb** - Comparative analysis of centroid-based vs density-based clustering methods

### AI_Agents
Agentic workflows combining language models with structured reasoning.
- **Groq_AI_Agents.ipynb** - Plan-Think-Act framework demonstrating autonomous decision-making pipelines

## Technologies
- TensorFlow/Keras
- PyTorch
- scikit-learn
- NumPy, Pandas, Matplotlib
